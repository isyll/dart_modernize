# dart_modernize

A CLI tool that modernizes Dart and Flutter codebases — applies idiomatic patterns, enforces conventions, and automates tedious upgrades.

## Installation

```sh
dart pub global activate dart_modernize
```

## Usage

```sh
dart_modernize [options] <path>

Options:
  -h, --help       Show usage.
  -v, --version    Show version.
```
